## 交付与限制

- 网关源代码补丁和构建方式见 [`patches/ai-gateway/README.md`](../../patches/ai-gateway/README.md)。本次已使用补丁构建完整 CCR 生产资源，并用本机模拟上游验证 Fusion JSON/SSE、工具 ID、日志及 HTTP 200 元数据。
- 网关补丁尚未进入公开 npm 版本；普通安装依赖并不会自动包含它。发布 CCR 前需要合入并发布网关补丁、升级依赖，或明确使用补丁源码构建。
- 插件市场仓库 404 需要维护者变更仓库可见性或提供有效地址，文档无法使远端仓库上线。
- 既有历史日志缺失的 HTTP 状态无法可靠还原；显示未知，不伪造成功。供应商与价格修复适用于后续入库记录，没有批量改写用户历史数据库。
- Jev 示例在明确启用后才发送最新用户文本摘要到配置的分类服务；测试使用模拟响应，未使用真实 API Key。
